OpenCode

把 OpenCode 的免费模型暴露为标准 OpenAI 接口：推荐走本机服务（实测稳定可用），云端匿名通道作为备用。

连接本机 OpenCode 服务 推荐

桌面端「设置 → 服务器」里那个连接地址（http://127.0.0.1:端口）就是本机 v2 API。 插件会自动读取 ~/.local/state/opencode/service.json 里的地址与密码， 所以通常直接点「自动发现并连接」即可；端口每次启动都会变，不要写死。 这条链路走的是本机客户端自己的会话，实测不受云端匿名额度限制。

前提：opencode 桌面端或 opencode serve 正在运行。连接成功后在 「模型 / 提供商」里选 opencode-local 这一家。

云端直连 备用

匿名车道不需要 Key，但上游按出口 IP 计免费额度，耗尽后返回 429 FreeUsageLimitError（换账号无效，通常要等十几小时）。 想用自己的 Zen / Go Key 提高额度或换通道，在下方手工粘贴即可（Key 优先）。 模型清单现在直接取自该通道的 /v1/models，不再混入上游不存在的模型。

可选：手工粘贴 API Key（覆盖匿名通道）

Key 在 opencode.ai/auth 创建。填写后点「添加 Key」，请求会走所选 Key 通道。 本插件只代理免费模型，付费模型请求会被拒绝。

基址写到通道根为止（…/zen 或 …/zen/go）， 不要带 /v1。留空 = 官方地址。
