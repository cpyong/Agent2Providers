WPS 灵犀

模型代理 · 智点余额 · 每日签到。支持打开浏览器一键登录；上游没有续期接口，登录态失效后重新登录即可。

添加账号

点下面的按钮会打开一个独立的 Chrome / Edge 窗口，用微信扫码或手机号登录 WPS 账号； 登录完成后插件会自动读取 wps_sid 并收下账号，不用 F12 复制 Cookie。 该窗口使用临时配置目录，不读取也不写入你日常浏览器的登录态，完成后自动关闭。

手动粘贴 Cookie（无浏览器环境时兜底）

打开 lingxi.kdocs.cn 并登录 → F12 → Network → 找到 tasks 请求 → 右键「复制 cURL」→ 把整段 Cookie 粘到下面。也支持只粘 wps_sid=… 或裸 sid。 Cookie 等于账号登录态，仅保存在网关账号库里；社区实测有效期约 30 天，且签到接口不会自动续期。

账号与签到

「签到」调任务中心 daily_check_in。插件会先读今日状态，再按领前/领后智点余额差与状态回查确认到账， 不会把上游的 HTTP 200 假成功当成已领。也可在网关「签到中心」里批量与定时签到。
