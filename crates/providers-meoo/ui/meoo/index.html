Meoo 秒悟

模型目录 · 积分余额 · 每日登录赠积分。用官方 OAuth 授权登录，或手填项目服务 AK；对话走 AI 网关的 OpenAI 兼容层。

添加账号

点下面的按钮会打开 Meoo 官方授权页（系统默认浏览器），登录并点一次「授权」； 浏览器会自动跳回本机回调，插件收下账号与项目服务 AK。走的是官方 OAuth PKCE， 不读取你浏览器的 Cookie，也不需要 F12 复制任何东西。 授权完成后浏览器标签页可以直接关掉。

正在启动登录…

浏览器没自动打开？点这里重新用系统浏览器打开授权页， 或复制下面的地址粘贴到任意浏览器（授权完成后会自动跳回本机，账号由插件收下）。

手动填写项目服务 AK（无浏览器环境时兜底）

粘贴 meoo_project_service_v1.…，或 Meoo CLI 导出的凭证 JSON。 只有 AK 的账号可以聊天、拉模型目录，但查不了积分也签不了到： 控制面要的是 OAuth access token，两套鉴权不能互换。AK 只保存在网关账号库里， 界面只显示末四位。

账号与签到

Meoo 没有独立签到接口：官方文档说「所有用户每日首次登录系统，均可免费获赠 2000 积分」。 插件做一次登录续期，再用领前 / 领后积分余额差确认是否真的到账；余额没涨但权益有效会报「今日已领」， 连余额都读不到则明确报失败 —— 不把 HTTP 200 当成功。也可在网关「签到中心」里批量与定时签到。
